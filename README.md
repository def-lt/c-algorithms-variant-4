# Алгоритмы на C. Разделы 01–06 — Вариант 4

Решения трёх задач на языке C.

## Задача 1 — Время суток (20 баллов)

Ввод: часы (0…23) и минуты (0…59).  
Вывод: часть суток (`night` / `morning` / `day` / `evening`) и время в 12-часовом формате.

```bash
gcc task1.c -o task1
./task1
```

## Задача 2 — fizzbuzz с делителями (35 баллов)

Ввод: `n` (1…1000), `p` и `q` (2…9, `p ≠ q`).  
Вывод: числа 1…n, заменяя кратные `p` на `fizz`, `q` на `buzz`, обоим — `fizzbuzz`.

```bash
gcc task2.c -o task2
./task2
```

## Задача 3 — Шахматная доска (45 баллов)

Ввод: `n` (1…20) — клеток в стороне, `k` (1…5) — размер клетки в символах.  
Вывод: доска (`.` — светлая, `#` — тёмная, левый верхний угол светлый).

```bash
gcc task3.c -o task3
./task3
```

При любом нарушении ограничений или ошибке ввода программа выводит `error` и завершается с кодом 1.
