# Алгоритмы на C/C++. Разделы 01–06 — Вариант 4

Решения трёх задач. Ввод — через `scanf`, без приглашений; при нарушении
ограничений выводится `error` и программа завершается с кодом 1.

## Задача 1 — Время суток (`task1_time_of_day.cpp`)

Ввод: часы (0..23) и минуты (0..59).
Вывод: часть суток — `night` (0–5), `morning` (6–11), `day` (12–17),
`evening` (18–23) — и время в 12-часовом формате `H:MM AM/PM`
(полночь — 12 AM, полдень — 12 PM).

    ввод: 0 5   ->  night 12:05 AM
    ввод: 12 0  ->  day 12:00 PM
    ввод: 24 0  ->  error            (код 1)

## Задача 2 — FizzBuzz с делителями (`task2_fizzbuzz.cpp`)

Ввод: n (1..1000), p и q (2..9, p != q).
Вывод в одну строку через пробел: числа 1..n, но кратное p — `fizz`,
кратное q — `buzz`, кратное обоим — `fizzbuzz`.

    ввод: 15 3 5  ->  1 2 fizz 4 buzz fizz 7 8 fizz buzz 11 fizz 13 14 fizzbuzz
    ввод: 10 2 4  ->  1 fizz 3 fizzbuzz 5 fizz 7 fizzbuzz 9 fizz
    ввод: 5 3 3    ->  error            (код 1)

## Задача 3 — Шахматная доска (`task3_chessboard.cpp`)

Ввод: n (1..20) — клеток в стороне доски, k (1..5) — сторона клетки в символах.
Вывод: доска, светлые клетки — `.`, тёмные — `#`, левая верхняя — светлая.

    ввод: 2 2  ->
    ..##
    ..##
    ##..
    ##..

    ввод: 0 1  ->  error            (код 1)

## Компиляция

    gcc task1_time_of_day.cpp -o task1   # или g++
    gcc task2_fizzbuzz.cpp -o task2
    gcc task3_chessboard.cpp -o task3
